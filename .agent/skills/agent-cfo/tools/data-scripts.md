# Инструмент: Продвинутая аналитика (Data Scripts)

Позволяет писать кастомные скрипты, выгружать сырые данные и запускать их в терминале для сложной математики и моделирования.

## Зачем использовать
- Расчет сложных вероятностных моделей (например, симуляция Монте-Карло для прогноза Cash Flow).
- Глубокий когортный анализ и расчет Retention, который слишком сложен или долго выполняется через чистый SQL.
- Сведение данных из базы (Supabase) с данными из внешних файлов или расчет кастомных формул Unit-экономики.

## Как использовать
1. Сформируй SQL-запрос для выгрузки сырых данных из БД (или используй моковые данные, если БД недоступна).
2. Создай временный скрипт на TypeScript/Node.js (например, в папке `.agent/scratch/` или просто в корне для тестов).
3. Запусти скрипт через инструмент терминала (`run_command`, например `npx tsx script.ts`).
4. Проанализируй вывод скрипта и сделай обоснованные бизнес-выводы.
