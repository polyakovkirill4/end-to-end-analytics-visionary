# Unit Economics — Компетенция CFO

## Ключевые метрики и формулы

### CAC (Customer Acquisition Cost)
```
CAC = Общие затраты на маркетинг и продажи за период
      ───────────────────────────────────────────────
      Количество новых клиентов за тот же период
```
- Считай отдельно по каналам (CAC_SEO ≠ CAC_PPC ≠ CAC_Referral)
- Хороший CAC для B2B SaaS: окупается за 12-18 месяцев

### LTV (Lifetime Value)
```
LTV = ARPU × Gross Margin %
      ──────────────────────
           Churn Rate
```
- ARPU (Average Revenue Per User) = MRR ÷ Кол-во платящих клиентов
- Gross Margin = (Выручка - COGS) ÷ Выручка × 100%
- Норма: LTV ≥ 3 × CAC

### CAC Payback Period
```
CAC Payback = CAC ÷ (ARPU × Gross Margin%)
```
- SaaS-норма: ≤ 12 месяцев для SMB, ≤ 18 мес для Enterprise

### Churn Rate (отток)
```
MRR Churn Rate = Потерянный MRR за месяц
                 ─────────────────────────
                 MRR на начало месяца

Logo Churn Rate = Кол-во ушедших клиентов
                  ─────────────────────────
                  Кол-во клиентов в начале
```

### NRR (Net Revenue Retention)
```
NRR = (Стартовый MRR - Churned MRR + Expansion MRR) ÷ Стартовый MRR × 100%
```
- NRR > 100% = компания растет даже без новых клиентов (expansion)
- Норма для SaaS: 110-130% = отличный продукт

---

## Как CFO оценивает фичи через Unit Economics

**При оценке новой фичи задай вопросы:**
1. Влияет ли на Churn? (удержание дороже привлечения)
2. Влияет ли на ARPU / Expansion? (upsell, tier upgrade)
3. Добавляет ли операционные расходы (COGS)?
4. Снижает ли CAC (виральность, referral)?

**Приоритет воздействия (по ROI):**
`Снижение Churn > Рост ARPU > Снижение CAC > Рост Top-of-Funnel`
