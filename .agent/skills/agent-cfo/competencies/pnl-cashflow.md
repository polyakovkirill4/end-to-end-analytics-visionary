# P&L и Cash Flow — Компетенция CFO

## Структура P&L (ОПиУ) для SaaS

```
Выручка (Revenue)
  - Стоимость продаж (COGS: хостинг, поддержка, CS)
= Валовая прибыль (Gross Profit) → Норма: 70-85% для SaaS

  - R&D (разработка, команда)
  - S&M (продажи и маркетинг)
  - G&A (административные расходы)
= EBITDA → операционная прибыль до налогов

  - Амортизация, проценты, налоги
= Чистая прибыль (Net Income)
```

**Нормы для SaaS на стадии роста:**
- Gross Margin: 70-85%
- R&D: 15-25% от выручки
- S&M: 30-50% от выручки (на ранних стадиях может быть выше)
- Rule of 40: рост выручки % + EBITDA margin % ≥ 40

---

## Cash Flow (ОДДС) — Кассовые разрывы

Прибыль ≠ деньги на счете. Компания может быть прибыльной, но с нулевым кешем.

**Ключевые риски Cash Flow в SaaS:**
- Клиенты платят помесячно → нет авансов → Cash Flow ровный, но нет резерва
- Переход на годовые подписки = разовый кеш, но потом тишина

**Метрики Cash Flow:**
- `Operating Cash Flow` — деньги от основной деятельности
- `Free Cash Flow = OCF - CapEx` — реально свободные деньги
- `Cash Runway` = Деньги на счете ÷ Ежемесячный burn rate

## Как CFO читает P&L при оценке фичи

При добавлении новой фичи CFO смотрит:
1. **Что растет в COGS?** (Инфраструктура, поддержка, CS)
2. **Что растет в S&M?** (Нужна ли дополнительная продажа?)
3. **Как меняется Gross Margin?** (Не снижает ли фича маржу)
4. **Когда окупается?** (ROI через X месяцев)
