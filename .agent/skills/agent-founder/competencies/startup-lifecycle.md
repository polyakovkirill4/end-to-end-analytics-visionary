# Эволюция Стартапа и Операционка — Компетенция Founder

Как запускать проекты без потери денег и как расшивать узкие места.

## Lean Startup (Бережливый стартап Эрика Риса)
Философия создания продукта в условиях крайней неопределенности:
1. **Build-Measure-Learn (Создать-Оценить-Научиться)**: Цикл создания MVP, замера реакций пользователей и адаптации. Цель — пройти этот цикл быстрее всех на рынке.
2. **Validated Learning**: Единственный измеритель прогресса стартапа — это не написанные строчки кода, а подтвержденное знание о том, что нужно клиенту.
3. **Pivot (Вираж)**: Изменение курса на основе данных, при сохранении глобального Видения.

## Этапы развития стартапа
1. **Discovery / Idea**: Поиск проблемы и CustDev. Фокус — найти боль.
2. **Validation / MVP**: Создание минимального решения. Поиск PMF (Product-Market Fit). Фокус — Retention.
3. **Efficiency**: Настройка Unit-экономики. Фокус — LTV > 3 CAC. Слишком раннее масштабирование на этом этапе убивает стартап.
4. **Scale (Масштабирование)**: Заливаем деньги в маркетинг. Фокус — рост (Growth).

## Теория ограничений Голдрата (TOC)
Любая система имеет узкое горлышко (Bottle-neck), которое определяет общую пропускную способность.
1. **Найди ограничение** (Например: маркетинг приносит 100 лидов, продукт переваривает 100, а отдел продаж успевает обработать только 10).
2. **Максимально используй ограничение** (Менеджеры по продажам не должны делать ничего, кроме звонков).
3. **Подчини всё остальное ограничению** (Маркетинг должен приостановить лиды или делать более жесткий скоринг).
4. **Расширь ограничение** (Найми еще сейлзов или автоматизируй звонки).

## Как Founder оценивает ситуацию:
«Зачем нам ускорять разработку фичей, если наше узкое горлышко по Голдрату — это процесс онбординга? Пользователи просто не доходят до этих фичей. Перенаправляем весь фокус на онбординг».
