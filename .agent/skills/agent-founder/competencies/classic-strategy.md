# Классическая Стратегия — Компетенция Founder

Фундаментальные бизнес-фреймворки для оценки конкуренции и портфеля продуктов.

## Анализ Пяти Сил Портера (Porter's Five Forces)
Определяет привлекательность и прибыльность рынка:
1. **Угроза появления новых игроков**: Насколько легко создать клон вашего SaaS? (Барьеры входа).
2. **Угроза товаров-заменителей**: Можно ли решить проблему клиента вообще без софта? (Например, нанять ассистента или юзать Excel).
3. **Рыночная власть покупателей**: Если у вас 3 крупных клиента, они будут диктовать вам цены. В SaaS с тысячами клиентов власть покупателей низкая.
4. **Рыночная власть поставщиков**: Если ваш SaaS на 100% зависит от API OpenAI, поставщик может забрать всю вашу маржу.
5. **Уровень конкурентной борьбы**: Сколько прямых конкурентов бьются за те же рекламные бюджеты.

## Стратегии конкуренции Портера
Компания может выиграть только если выберет одну из 3 стратегий (иначе "застрянет посередине"):
1. **Лидерство в издержках**: Самый дешевый продукт за счет масштаба.
2. **Дифференциация**: Уникальный продукт, за который платят премиум-цену (например, лучший дизайн или уникальные фичи).
3. **Фокусирование (Ниша)**: Продукт, идеально заточенный под один узкий сегмент (например, CRM только для стоматологий).

## Матрица BCG
Для распределения инвестиций между фичами или продуктами компании:
- **Звезды (Stars)**: Быстрый рост, большая доля рынка. Инвестируем всё сюда.
- **Дойные коровы (Cash Cows)**: Медленный рост, но большая доля рынка. Приносят основную прибыль. Не меняем, просто поддерживаем.
- **Трудные дети / Знаки вопроса**: Быстрый рост рынка, но наша доля мала. Требуют решений — либо агрессивно вливать деньги, либо закрывать.
- **Собаки (Dogs)**: Медленный рост, малая доля. Закрываем немедленно (Kill the feature).

## Как Founder оценивает ситуацию:
«Наш модуль X превратился в "Собаку" по матрице BCG — он съедает ресурс разработки, но не приносит новых клиентов. Мы его закрываем и перебрасываем команду на "Звезду" — модуль Y».
