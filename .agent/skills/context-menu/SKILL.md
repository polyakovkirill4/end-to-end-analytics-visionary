# Правила разработки и реализации контекстных меню (ContextMenu)

Этот документ описывает универсальные стандарты создания кастомных контекстных меню. Контекстные меню должны отлично работать на настольных компьютерах (правый клик) и на мобильных устройствах (долгое нажатие), рендериться поверх любого контента без обрезания границами родительских контейнеров и плавно анимироваться.

---

## 1. Архитектура компонента

Контекстное меню реализуется через паттерн Compound Components и использует React Context для синхронизации состояния:
- `ContextMenu` — корневой компонент, хранящий состояние открытия (`isOpen`) и координаты вызова (`x`, `y`).
- `ContextMenuTrigger` — область, на которую кликают правой кнопкой мыши или совершают долгое касание.
- `ContextMenuContent` — портал (Portal), рендерящий элементы меню в `document.body` для предотвращения обрезания стилями `overflow: hidden`.
- `ContextMenuItem` — пункт меню.
- `ContextMenuSeparator` — декоративный разделитель между группами действий.

---

## 2. Поддержка платформ и жесты

### Desktop: Правый клик
- Отслеживание события `onContextMenu` на триггере.
- Обязательный вызов методов `preventDefault()` и `stopPropagation()` для предотвращения открытия стандартного меню браузера.

### Mobile: Долгое нажатие (Long Press)
- Отслеживание тач-событий на триггере: `onTouchStart`, `onTouchMove`, `onTouchEnd`, `onTouchCancel`.
- **Запуск таймера**: При событии начала касания запускается таймер на **600мс**.
- **Сброс таймера**:
  - Если во время касания палец сместился более чем на **10px** в любую сторону (событие движения пальца), таймер сбрасывается.
  - Если касание завершилось раньше истечения 600мс, таймер сбрасывается.
- **Тактильный виброотклик**: При срабатывании лонг-пресса (вызове меню) отправляется легкий виброимпульс на устройство:
  ```typescript
  if (typeof window !== 'undefined' && window.navigator?.vibrate) {
    window.navigator.vibrate(40); // 40мс
  }
  ```
- **Предотвращение выделения**: На триггер вешаются CSS-стили, отключающие стандартное выделение текста и вызов системного меню (например, `user-select: none`, `-webkit-touch-callout: none`).

## 3. Позиционирование и Расчет коллизий (Collision Detection)

Для предотвращения коллизий с краями экрана (когда меню открывается слишком близко к правому или нижнему краю и уходит за пределы видимости) позиционирование рассчитывается динамически.

### Корректировка позиции (Внутренний компонент меню):
- Внутри портала координаты меню (`x`, `y`) корректируются перед отрисовкой (например, с помощью `useLayoutEffect`), чтобы меню всегда оставалось полностью во вьюпорте.
- **Алгоритм корректировки**:
  ```typescript
  useLayoutEffect(() => {
    if (!menuRef.current) return;
    const rect = menuRef.current.getBoundingClientRect();
    const width = rect.width;
    const height = rect.height;
    let posX = x;
    let posY = y;
    const margin = 12; // Безопасный отступ от краев экрана

    // Если выходит за правый край
    if (posX + width > window.innerWidth) {
      posX = window.innerWidth - width - margin;
    }
    // Если выходит за нижний край
    if (posY + height > window.innerHeight) {
      posY = window.innerHeight - height - margin;
    }
    // Если выходит за левый край
    if (posX < margin) {
      posX = margin;
    }
    // Если выходит за верхний край
    if (posY < margin) {
      posY = margin;
    }

    setAdjustedCoords({ x: posX, y: posY });
  }, [x, y]);
  ```

## 4. Жизненный цикл и Закрытие меню

Контекстное меню должно автоматически закрываться в следующих случаях:
1. **Клик снаружи**: Клик по любому элементу, который не находится внутри меню.
   - *Важно*: Навешивать глобальные слушатели клика на `document` нужно с минимальной задержкой (например, `setTimeout(..., 10)`), чтобы избежать мгновенного закрытия меню от того же клика, который его инициировал.
2. **Клавиша Escape**: Навешивается слушатель события `keydown` на документ.
3. **Прокрутка (Scroll)**: Событие прокрутки окна должно мгновенно закрывать меню, чтобы оно не отрывалось от своего триггера.
4. **Изменение размера окна (Resize)**: Изменение размеров окна закрывает меню.
5. **Клик по пункту**: Выбор любого пункта меню выполняет действие и закрывает меню.

## 5. UI/UX стандарты и Стилизация

- **Анимация**: Появление меню должно быть плавным, с легким масштабированием (scale) и проявлением прозрачности (opacity) за короткий промежуток времени (около 0.1–0.15 секунды).
- **Дизайн**:
  - Контейнер меню: полупрозрачный фон, размытие заднего плана (backdrop-blur), тонкая рамка, скругленные углы и мягкая тень. Должна быть обеспечена поддержка темной и светлой тем.
  - Пункты меню: интерактивные кнопки с горизонтальной ориентацией, поддерживающие отображение иконок слева, текста по центру и опциональных горячих клавиш (shortcuts) справа.
  - Состояния: ховер-эффекты (выделение фоновым цветом бренда или нейтральным оттенком), активные состояния при нажатии (с легким микро-масштабированием).
  - Опасные действия (Удалить и т.п.): выделяются контрастным цветом опасности (красным/деструктивным) и специальным флагом danger.
  - Разделители: тонкая контрастная линия для визуального разделения групп элементов.
