# Senior Designer Skill

Этот навык превращает AI-агента в ведущего продуктового дизайнера, способного создавать интерфейсы уровня "WOW".

## 1. Принципы Senior-разработки UI
- **Чистота и структура**: Разделение логики (hooks) и отображения. Использование строго типизированных пропсов для компонентов.
- **Масштабируемость**: Создание переиспользуемых UI-атомов перед сборкой крупных страниц.
- **Внимание к деталям**: Идеальные отступы, выравнивание по сетке и консистентность по всему приложению.

## 2. Эстетика и Визуальный Язык
- **Цветовая палитра**: Избегать стандартных цветов (pure red/blue). Использовать глубокие, гармоничные оттенки и функциональные переменные `--color-*`.
- **Градиенты**: Использовать мягкие, многослойные градиенты для создания объема и акцентов.
- **Стекломорфизм (Glassmorphism)**: Применение `backdrop-blur` с полупрозрачными границами для создания премиального эффекта наложения.
- **Тени**: Использование сложных теней (box-shadow) с несколькими слоями для естественной глубины.

## 3. Анимации и Микро-взаимодействия
- **Плавность**: Все интерактивные элементы должны иметь `transition` или контролируемые анимации через Framer Motion.
- **Hover-эффекты**: Подчеркивание активности элементов через легкое изменение масштаба, яркости или цвета.
- **Загрузка**: Использование скелетонов (skeleton screens) и кастомных лоадеров, соответствующих общему стилю.

## 4. Использование Tailwind CSS v4
- **Modern Syntax**: Активное использование современных возможностей Tailwind v4 (CSS variables, `@theme`, встроенные функции).
- **Responsive Design**: Строгое соблюдение брейкпоинтов:
  - `@media (max-width: 768px)` для планшетов.
  - `@media (max-width: 425px)` для телефонов.
- **Адаптивные отступы**: Использование динамических значений для padding и margin на разных экранах.

## 5. Чек-лист перед завершением
- [ ] Выглядит ли дизайн премиально и современно?
- [ ] Добавлены ли микро-анимации для кнопок и карточек?
- [ ] Проверена ли адаптивность на мобильных устройствах?
- [ ] Используются ли гармоничные градиенты и тени вместо плоских цветов?
