# Правила проектирования и реализации центра уведомлений (Notifications)

Этот документ описывает универсальные стандарты проектирования и разработки системы уведомлений в веб-приложениях. Он включает в себя правила для выпадающей панели (Popover Panel), полноэкранного центра уведомлений (Notifications Page), автоматического прочтения при скролле и интеграции с контекстными меню.

---

## 1. Архитектурная структура

Система уведомлений состоит из следующих абстрактных слоев:
1. **База данных**: Таблица или коллекция `notifications` с полями: `id` (UUID/уникальный ключ), `user_id` (ссылка на пользователя), `title` (заголовок), `message` (текст уведомления), `type` (тип: info, warning, success, alert), `is_read` (флаг прочтения), `link` (необязательная ссылка для перехода), `created_at` (дата создания).
2. **Сервисный слой** (например, в папке сервисов): Асинхронные методы API для получения списка уведомлений, пометки одного или всех уведомлений прочитанными, а также их удаления.
3. **Глобальный стейт**: Механизм управления состоянием на клиенте для мгновенного обновления UI при получении новых уведомлений или изменении статуса прочтения.
4. **Компоненты интерфейса**:
   - Панель уведомлений (Popover) — выпадающее меню, прикрепленное к триггеру (иконке колокольчика).
   - Страница уведомлений (View) — полноэкранный интерфейс с возможностью фильтрации и постраничного просмотра.
   - Карточка уведомления (Item) — отдельный элемент списка уведомлений.
5. **Кастомные React-хуки**:
   - Автоматическое прочтение при просмотре — логика отслеживания видимости элемента на базе Intersection Observer.
   - Закрытие при клике вне области — логика скрытия панели при клике на другие области экрана.

---

## 2. Автоматическое прочтение (Auto-Read)

Для повышения удобства использования непрочитанные уведомления должны автоматически отмечаться как прочитанные, когда пользователь видит их на экране в течение определенного времени.

### Правила реализации Auto-Read:
- **Использование Intersection Observer**: Логика вешается на элемент карточки уведомления.
- **Параметры видимости**:
  - `threshold` (порог видимости): `0.9` (элемент должен быть виден во вьюпорте минимум на 90%).
  - `delayMs` (задержка): `2000` (2 секунды непрерывной видимости перед вызовом API для предотвращения случайных срабатываний при быстром скролле).
- **Ручной сброс (Manual Unread Prevent)**: Если пользователь вручную отметил уведомление как "Непрочитанное" (например, через контекстное меню), автопрочтение **не должно** повторно срабатывать для этого элемента, пока он не выйдет из зоны видимости и не зайдет туда снова.
  - Для этого используется флаг ручного сброса (например, `wasManuallyUnread`), который сбрасывается только при потере видимости элемента (`isIntersecting === false`).

### Шаблон универсального хука `useNotificationAutoRead`:
```typescript
'use client';

import { useEffect, useRef, useState } from 'react';

interface UseNotificationAutoReadProps {
  id: string;
  isRead: boolean;
  onMarkAsRead: (id: string) => void;
  threshold?: number;
  delayMs?: number;
}

export function useNotificationAutoRead<T extends HTMLElement = HTMLDivElement>({
  id,
  isRead,
  onMarkAsRead,
  threshold = 0.9,
  delayMs = 2000,
}: UseNotificationAutoReadProps) {
  const [wasManuallyUnread, setWasManuallyUnread] = useState(false);
  const elementRef = useRef<T>(null);

  useEffect(() => {
    if (isRead) return;

    let timeoutId: NodeJS.Timeout;

    const observer = new IntersectionObserver(
      (entries) => {
        const entry = entries[0];
        if (entry.isIntersecting && entry.intersectionRatio >= threshold) {
          if (!wasManuallyUnread) {
            timeoutId = setTimeout(() => {
              onMarkAsRead(id);
            }, delayMs);
          }
        } else {
          clearTimeout(timeoutId);
          setWasManuallyUnread(false);
        }
      },
      { threshold }
    );

    const currentElement = elementRef.current;
    if (currentElement) {
      observer.observe(currentElement);
    }

    return () => {
      if (currentElement) {
        observer.unobserve(currentElement);
      }
      observer.disconnect();
      clearTimeout(timeoutId);
    };
  }, [id, isRead, onMarkAsRead, wasManuallyUnread, threshold, delayMs]);

  return {
    ref: elementRef,
    wasManuallyUnread,
    setWasManuallyUnread,
  };
}
```

## 3. Закрытие панели при клике вовне (Click Outside)

Выпадающая панель уведомлений должна автоматически закрываться при клике в любое другое место экрана.

### Правила реализации:
- Используется кастомный хук или обработчик события клика вне области (Click Outside).
- **Исключения**: Клик по кнопке-триггеру (колокольчику) **не должен** вызывать закрытие (иначе панель закроется сразу в момент клика).
- **Исключения для контекстного меню**: Если клик произошел по элементам контекстного меню (порталу действий), закрывать панель **не нужно**, так как пользователь взаимодействует с опциями самого уведомления.

## 4. UI/UX стандарты и Эстетика

- **Анимации**: Открытие и закрытие панели анимируется плавно с изменением прозрачности, легким сдвигом и масштабированием (например, средствами CSS-переходов или библиотек анимаций).
- **Стилизация**:
  - Панель: размытие фона (backdrop-blur), полупрозрачный фоновый цвет с поддержкой темного и светлого режимов, мягкая тень и аккуратная граница для отделения от основного контента.
  - Элементы списка: непрочитанные элементы визуально выделяются легким фоновым оттенком бренда и контрастным цветным индикатором (точкой). Прочитанные элементы имеют полупрозрачность или стандартный нейтральный фон списка.
- **Действия**: Каждый элемент списка уведомлений должен поддерживать быстрые действия (например, через контекстное меню или кнопки быстрого доступа):
  - Отметить прочитанным / непрочитанным.
  - Перейти по ссылке (если есть целевой раздел).
  - Удалить уведомление.
- **Адаптивность**: На мобильных устройствах панель должна адаптироваться: либо растягиваться на весь экран, либо трансформироваться в нижнюю шторку (Bottom Sheet) с крупными тач-зонами (минимум 44x44px).
