# Стандарты Форматирования UI (МСФО)

| Элемент | Формат в UI |
|---------|--------|
| Хардкодные инпуты (Допущения) | Синий цвет текста (или акцентный Tailwind класс, например `text-indigo-600`) |
| Расчетные формулы (Readonly) | Черный/Темно-серый текст (`text-slate-900`) |
| Ссылки на другие отчеты | Зеленый цвет текста (`text-emerald-600`) |
| Ячейки проверки (Checks) | Красный при ошибке, зеленый/прозрачный при успехе |
| Отрицательные значения | знака минуса, никаких скобок на отрицательных цифр нет (например: `- 1 500`) |
| Валюта | Без копеек для крупных сумм, 2 знака для удельных показателей |
| Проценты | 1 знак после запятой |
| Заголовки таблиц | Жирный шрифт, нижняя рамка (`border-b border-slate-300`) |
| Строка единиц измерения | Под заголовками (млн ₽, %, и т.д.) |

## Правила Визуального Разделения

- Тонкая вертикальная граница между историческими (A) и прогнозными (E) колонками.
- Жирная нижняя граница после секционных итогов (например, Итого Активы).
- Одинарная нижняя граница для промежуточных итогов (Subtotals).
- Двойная нижняя граница для глобальных итогов (Grand totals).

## Форматирование Строк Итогов

Все строки итогов и промежуточных итогов должны использовать **жирный шрифт** (`font-bold`) для числовых значений, чтобы визуально отличать агрегацию от обычных строк.

### ОПиУ (P&L)
- Валовая Выручка (Gross Revenue) → **Жирный**
- Валовая Прибыль (Gross Profit) → **Жирный**
- Итого SG&A → **Жирный**
- EBITDA → **Жирный**
- EBIT → **Жирный**
- EBT → **Жирный**
- Чистая прибыль (Net Profit After Tax) → **Жирный**

### Баланс (Balance Sheet)
- Итого Оборотные Активы → **Жирный**
- Итого Внеоборотные Активы → **Жирный**
- Итого Активы (Total Assets) → **Жирный**
- Итого Обязательства → **Жирный**
- Итого Капитал → **Жирный**
- Итого Пассивы и Капитал → **Жирный**

### ОДДС (Cash Flow)
- Денежный поток от Операционной Деятельности (CFO) → **Жирный**
- Изменения рабочего капитала → **Жирный**
- Денежный поток от Инвестиционной Деятельности (CFI) → **Жирный**
- Денежный поток от Финансовой Деятельности (CFF) → **Жирный**
- Конечный баланс Кэша → **Жирный**

## Форматирование Строки Проверки Баланса (Check Row)

Строка проверки баланса (в самом низу под Итого Пассивами) использует условное форматирование. Если баланс сходится (`check === 0`), значения отображаются стандартным цветом. Если есть отклонение — красным.

| Значение проверки | Цвет шрифта (Tailwind) |
|-------------|------------|
| `=== 0` (сходится) | Стандартный (`text-slate-900` или `text-slate-500`) |
| `!== 0` (ошибка) | Красный (`text-rose-600 font-bold`) |

## Форматирование Строк Маржинальности

- Строки с % маржи: отступ слева, курсив (`italic text-slate-500`), 1 знак после запятой.
- Положительный тренд: стандартный цвет или легкий зеленый (`text-emerald-600`).
- Отрицательный тренд: флаг для проверки (легкий желтый/красный).

## Пороги Цветовой Индикации (Кредитные Метрики)

Если платформа выводит дашборд здоровья, используйте эти цвета (Green / Yellow / Red):

| Метрика | Зеленый (Успех) | Желтый (Внимание) | Красный (Риск) |
|--------|-------|--------|-----|
| Total Debt / EBITDA | < 2.5x | 2.5x - 4.0x | > 4.0x |
| Net Debt / EBITDA | < 2.0x | 2.0x - 3.5x | > 3.5x |
| Покрытие процентов | > 4.0x | 2.5x - 4.0x | < 2.5x |
| Debt / Total Cap | < 40% | 40% - 60% | > 60% |
| Текущая ликвидность | > 1.5x | 1.0x - 1.5x | < 1.0x |
| Быстрая ликвидность | > 1.0x | 0.75x - 1.0x | < 0.75x |

## Флаги Аномалий Маржинальности (Reasonability Flags)

Программный движок должен выдавать Warning (предупреждения) в UI:
- Валовая маржа < 0% → ОШИБКА: Проверьте COGS (Себестоимость превышает выручку).
- Валовая маржа > 80% → ПРЕДУПРЕЖДЕНИЕ: Проверьте адекватность выручки/COGS.
- EBITDA Маржа < 0% → ФЛАГ: Операционные убытки.
- EBITDA Маржа > 50% → ПРЕДУПРЕЖДЕНИЕ: Необычно высокая для SaaS.
- Чистая Маржа > Валовая Маржа → ОШИБКА: Математический конфликт.
