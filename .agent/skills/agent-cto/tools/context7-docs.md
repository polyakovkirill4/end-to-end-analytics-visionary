# Инструмент: Запросы к документации библиотек через Context7

Позволяет получать самую актуальную документацию по используемым библиотекам и фреймворкам прямо из MCP-сервера `context7`.

## Зачем использовать
- Проверить актуальный синтаксис библиотек (например, React 19 hooks, Next.js 15 routing, Tailwind CSS v4 directives).
- Найти правильные способы интеграции сторонних пакетов (Zustand, TanStack Query, Motion).
- Избежать использования устаревшего (deprecated) API из обучающей выборки модели.

## Как использовать
1. Сначала вызови инструмент `mcp_context7_resolve-library-id`, передав название библиотеки (например, `Next.js`, `Zustand`, `Tailwind CSS`).
2. Используй полученный ID библиотеки в инструменте `mcp_context7_query-docs`, чтобы задать конкретный вопрос (например, "How to write dynamic metadata in Next.js 15 App Router?").
3. Не вызывай этот инструмент более 3 раз за один вопрос, используй полученные примеры для написания кода.
