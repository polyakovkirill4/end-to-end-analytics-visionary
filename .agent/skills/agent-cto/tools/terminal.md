# Инструмент: Локальный терминал и выполнение команд

Позволяет запускать сборку проекта, проверку линтером или тестами для подтверждения корректности написанного кода.

## Зачем использовать
- Проверить сборку проекта через `npm run build` для обнаружения скрытых ошибок компиляции TypeScript.
- Проверить отсутствие ошибок форматирования и линтинга.
- Не запускай тестирование в браузере (браузерный сабагент), если пользователь об этом прямо не попросил.

## Как использовать
1. Используй `run_command` для запуска неразрушающих команд (например, `npm run build`).
2. Запрещено выполнять команды `cd`.
3. Указывай `Cwd` строго в пределах рабочей директории проекта.
4. Отслеживай результаты выполнения с помощью `command_status`.
