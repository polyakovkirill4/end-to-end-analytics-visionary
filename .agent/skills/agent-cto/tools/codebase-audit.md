# Инструмент: Аудит исходного кода (Codebase)

Позволяет анализировать структуру проекта, проверять типы TypeScript, импорты и существующие компоненты для исключения дублирования логики.

## Зачем использовать
- Проверить наличие готовых типов в `src/types/` и сервисов в `src/services/` перед написанием новых.
- Проанализировать существующие компоненты в `src/components/`, чтобы наследовать их дизайн и стили.
- Проверить, как реализованы аналогичные решения в других частях проекта.

## Как использовать
1. Используй `grep_search` для поиска ключевых слов, типов и названий компонентов.
2. Используй `list_dir` для изучения структуры папок, в которых планируется работа.
3. Используй `view_file` для детального разбора кода файлов, которые планируешь изменить.
