# Архитектура и технические стандарты Visionary

Этот документ описывает стандарты построения кодовой базы платформы, которым должен строго следовать ИИ-агент при написании кода.

## 1. Структура проекта (Next.js 15 & React 19)
- **Маршрутизация**: Проект использует Next.js App Router. Маршруты размещаются в `src/app/`.
- **Группы маршрутов (Route Groups)**:
  - `(auth)/` — авторизация, регистрация, восстановление пароля (чистый интерфейс без глобального сайдбара).
  - `(main)/` — основная рабочая область пользователя, наследующая глобальный Sidebar, Header и Footer.
- **Страницы (`page.tsx`)**: Должны быть "тонкими" компонентами. Они импортируют представления (View-компоненты) из соответствующих папок, передавая им необходимые параметры.
- **API эндпоинты**: Размещаются в `src/app/api/` и реализуются через Route Handlers. Вся сложная логика выносится в сервисы в `src/services/`.

## 2. Разделение компонентов (Server vs Client)
- **Server Components (по умолчанию)**: Используются для разметки страниц, загрузки первоначальных данных и SEO-оптимизации. Не содержат хуков состояния (useState, useEffect) или обработчиков событий.
- **Client Components (`'use client'`)**: Используются для интерактивных элементов, форм, модальных окон, графиков и компонентов со стейтом. Директива `'use client'` должна находиться на первой строке файла.

## 3. Стилизация (Tailwind CSS v4 & CSS Variables)
- Используется CSS-первый подход Tailwind CSS v4. Конфигурация темы находится в `src/app/globals.css` через директиву `@theme`.
- **Фирменные стили**:
  - Карточки: `bg-white rounded-2xl border border-slate-100 shadow-sm`.
  - Поля ввода: `h-11 px-4 rounded-xl border border-slate-200 focus:outline-none focus:ring-2 focus:ring-indigo-500/20 focus:border-indigo-600 transition-all`.
  - Кнопки: `bg-indigo-600 text-white hover:bg-indigo-700 active:scale-95 transition-all shadow-md shadow-indigo-600/10 rounded-xl px-5 py-2.5 font-bold`.
- **Адаптивность (Mobile First)**:
  - Использовать брейкпоинты `@media (max-width: 768px)` для планшетов и `@media (max-width: 425px)` для мобильных.
  - Тач-зоны для интерактивных элементов должны быть минимум 44x44px.
  - Избегать появления горизонтальной прокрутки, сжимать отступы и размеры шрифтов на малых экранах.

## 4. Качество кода и типизация
- **Строгая типизация**: Запрещено использование `any`. Все типы пропсов компонентов описываются как `[ComponentName]Props`.
- **Импорты**: Использовать абсолютные пути с алиасом `@/` (например, `import { Button } from '@/components/ui/button'`). Относительные пути через `../` запрещены.
- **Обработка ошибок**: Каждое действие пользователя, связанное с отправкой данных или запросами, должно содержать `try-catch` блоки с выводом красивых тостов или статусных сообщений об ошибках в UI.
