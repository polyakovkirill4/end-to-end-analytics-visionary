# Воронки и Конверсии — Компетенция CMO

## Типовая воронка B2B SaaS

```
[Посетитель] → [Лид] → [Trial/Demo] → [Активный пробный] → [Платящий] → [Лояльный]
   100%           5%        30%              60%                 20%           80%
```

**Ключевые точки конверсии для CMO:**

### 1. Visitor → Lead (Attraction)
- Оффер: что пользователь получает в обмен на контакт?
- Нормы: 2-5% для контентного сайта, 10-20% для лендинга под конкретный запрос
- Рычаги: CTA, копирайтинг, social proof, скорость загрузки

### 2. Lead → Trial (Activation Interest)
- Нормы: 20-40% от лидов
- Рычаги: nurturing email-цепочка, ретаргетинг, case studies

### 3. Trial → Paid (Monetization)
- Нормы: 15-25% (хороший продукт), <5% — проблема с onboarding или ценностью
- Рычаги: первая ценность как можно быстрее, правильный onboarding, персонализация

### 4. Paid → Retained (Loyalty)
- Нормы: 90%+ ежемесячный Retention (Logo)
- Рычаги: Customer Success, product engagement, expansion features

## Фреймворк Value Ladder (Лестница ценности)

```
[Бесплатный контент / Лид-магнит]  ← привлечь
        ↓
[Tripwire — низкий чек, высокая ценность] ← снизить риск первой покупки
        ↓
[Основной продукт (Core Offer)]    ← основная монетизация
        ↓
[Profit Maximizer — upsell/cross-sell] ← расширение
        ↓
[Return Path — удержание и повторные покупки] ← retention
```

## Как CMO улучшает воронку через продуктовые фичи

Каждая новая фича может влиять на разные этапы воронки:

| Тип фичи | Этап воронки | Что улучшается |
|:---|:---|:---|
| Новый виджет/отчет | Trial→Paid | Скорость Aha-момента |
| Интеграции | Paid→Retained | Stickiness, lock-in |
| Шаринг/экспорт | Visitor→Lead | Виральность, referral |
| Уведомления/инсайты | Paid→Retained | DAU, вовлеченность |
| Публичные дашборды | Visitor→Lead | Brand awareness |
