# Инструмент: Веб-поиск (Конкурентная разведка)

Описывает, как использовать системный инструмент веб-поиска (`search_web`) для анализа рынка и конкурентов.

## Зачем использовать
- Поиск публичной информации о конкурентах (их цены, позиционирование, УТП, отзывы).
- Поиск бенчмарков (например, "average B2B SaaS conversion rate 2026", "LTV to CAC ratio benchmarks").
- Сбор данных для анализа TAM/SAM/SOM или маркетинговых трендов в отрасли.

## Как использовать
1. Вызови инструмент `search_web` с конкретным запросом (на английском языке поиск обычно дает больше релевантных SaaS-бенчмарков).
2. Обязательно анализируй несколько источников, чтобы получить объективную картину, а не мнение одного блогера.
3. Интегрируй найденные бенчмарки в свои продуктовые и маркетинговые рекомендации.
