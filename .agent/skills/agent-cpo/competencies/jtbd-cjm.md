# JTBD и CJM — Компетенция CPO

## Jobs To Be Done (JTBD)

**Суть**: Люди не покупают продукт — они нанимают его для выполнения «работы».

```
JTBD-формула:
«Когда [ситуация], я хочу [мотивация], чтобы [ожидаемый результат]»

Пример:
«Когда я готовлюсь к встрече с инвесторами,
 я хочу быстро собрать ключевые финансовые метрики,
 чтобы выглядеть уверенно и профессионально»
```

### Как применять при оценке фичи

1. Сформулируй Job пользователя для этой фичи
2. Проверь: это Functional Job (сделать что-то), Emotional Job (почувствовать что-то) или Social Job (выглядеть как-то)?
3. Найди текущее решение пользователя (JTBD конкурент — не только прямой продукт, но Excel, блокнот, совещание)
4. Оцени: насколько мы делаем эту работу лучше конкурента?

## Customer Journey Map (CJM)

Карта пути клиента — от первого касания до лояльности:

```
[Осознание] → [Исследование] → [Оценка] → [Покупка] → [Активация] → [Регулярное Использование] → [Лояльность/Отток]
```

**Для каждого этапа CPO отвечает на:**
- Что пользователь **делает** на этом этапе?
- Что он **думает** и **чувствует**?
- Где **точки трения** (Pain Points)?
- Какие **возможности** для улучшения?

### Критические точки CJM

| Этап | Ключевой вопрос | Риск |
|:---|:---|:---|
| Активация | Получил ли пользователь первую ценность за 5 мин? | Churn в первую неделю |
| Привычка | Есть ли повод возвращаться каждую неделю? | Low WAU |
| Расширение | Видит ли ценность в платном тарифе? | Застревание на Free |
