# Продуктовые Метрики — Компетенция CPO

## Активность пользователей

### DAU / WAU / MAU
- **DAU** — Daily Active Users (ежедневные активные)
- **WAU** — Weekly Active Users
- **MAU** — Monthly Active Users

```
Stickiness = DAU ÷ MAU × 100%
```
- Stickiness > 20% — хороший продукт
- Stickiness > 50% — отличный (WhatsApp, Slack)
- Для B2B аналитики норма: 30-40%

## Retention (Удержание)

### Day-N Retention
```
Retention D7 = пользователи, вернувшиеся через 7 дней после регистрации
                ──────────────────────────────────────────────────────────
                         всего зарегистрировалось в тот день
```

**Нормы для B2B SaaS:**
- D1: 40-60%
- D7: 20-35%
- D30: 15-25%

### Feature Retention — как оценить фичу
```
Feature Retention = % пользователей, использующих фичу повторно через 14 дней
```
- < 10% — фича не нужна, убираем или переделываем
- 10-30% — нишевая, оставляем для нужного сегмента
- > 30% — ключевая, развиваем

---

## NPS (Net Promoter Score)

```
NPS = % Промоутеров (9-10) - % Критиков (0-6)
```
- NPS > 50 — отличный продукт
- NPS 30-50 — хороший
- NPS < 0 — проблемы с продуктом

**Вопросы для качественного NPS:**
- «Что заставило вас поставить такую оценку?»
- «Что одно мы можем улучшить?»

---

## Feature Adoption Rate

```
Adoption Rate = Пользователи, использовавшие фичу хотя бы раз
                ─────────────────────────────────────────────────
                         Всего активных пользователей
```

Если через 30 дней Adoption < 5% — фича незаметна. Проблема в Discovery, не в фиче.
