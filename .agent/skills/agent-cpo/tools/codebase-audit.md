# Инструмент: Аудит исходного кода (Codebase)

Позволяет изучать кодовую базу продукта, чтобы понять, как бизнес-логика реально работает "под капотом", а не только на уровне интерфейса.

## Зачем использовать
- Проверка хардкода (например, тарифных лимитов, ценников, конфигураций биллинга).
- Аудит фронтенда (найти, какие метрики аналитики и UTM-метки реально срабатывают на кнопках).
- Понимание скрытых механик (алгоритмы сортировки, ограничения функционала, логика онбординга).

## Как использовать
1. Используй инструмент `grep_search` для поиска ключевых бизнес-терминов (например, `stripe`, `utm_source`, `pricing`, `features`, `onboarding`).
2. Используй `view_file`, чтобы прочитать найденные файлы логики и конфигураций.
3. Сопоставь реальный код продукта с тем, как это должно работать по бизнес-требованиям, и укажи команде на разрывы (Gaps).
