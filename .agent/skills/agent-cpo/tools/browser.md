# Инструмент: Браузерный анализ (Browser Subagent)

Позволяет визуально оценить пользовательский интерфейс (UI) и пользовательский опыт (UX) продукта, пройти сценарии и онбординг.

## Зачем использовать
- Проверка реального пути пользователя (Customer Journey)
- Анализ новых фичей (поиск UX-трений, оценка когнитивной нагрузки)
- Аудит онбординга (Onboarding) и процесса активации (Activation)
- Оценка адаптивности и удобства использования на мобильных устройствах

## Как использовать
Если тебе нужно проверить, как реализована фича, ты можешь запустить `browser_subagent` (или попросить оркестратора это сделать), передав четкую продуктовую задачу:

- *"Открой страницу `/dashboard` и проанализируй, насколько очевидно для нового пользователя, как создать первый отчет."*
- *"Пройди интерактивный тур (онбординг) и оцени, не перегружает ли он внимание."*
- *"Открой интерфейс настроек профиля и посмотри, интуитивно ли расположены элементы управления."*

В результате сабагент вернет описание интерфейса, состояние элементов или скриншоты. На основе этого ты сможешь дать экспертное заключение: удобно ли это, и где пользователи могут "отваливаться" (Churn risk).
