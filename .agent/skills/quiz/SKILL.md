# Правила проектирования и реализации квизов

Этот документ описывает стандарты создания квизов (пошаговых опросов) для сбора данных от пользователей.

## 1. Архитектура компонента

- **Универсальность**: Компонент `QuizModal` должен быть полностью отделен от бизнес-логики. Все вопросы, варианты ответов и обработчики (onComplete) передаются через props.
- **Масштабируемость**: Квиз должен поддерживать неограниченное количество вопросов.
- **Типы вопросов**: Компонент должен аппаратно поддерживать различные типы ввода данных:
  - `number` — числовой ввод
  - `single-choice` — выбор одного варианта (radio)
  - `multiple-choice` — выбор нескольких вариантов (checkbox)

## 2. Дизайн и UX

- **Модальное окно**: Квиз должен открываться поверх всего интерфейса (z-index: 50+), с затемненным фоном (backdrop-blur или bg-black/50).
- **Шапка**: Заголовок квиза и краткое поясняющее предложение (описание цели сбора данных).
- **Навигация**:
  - Кнопка "Назад" (ghost/outline), скрыта на первом шаге.
  - Кнопка "Далее" (primary), заблокирована (disabled), если обязательный ответ не предоставлен.
  - Кнопка "Завершить" на последнем шаге.
- **Индикация прогресса**: Простой текст вида "Вопрос 1 из 3" или прогресс-бар.
- **Анимации**: Плавные переходы (fade-in) при смене вопросов.
- **Состояние загрузки**: При отправке данных на последнем шаге показать сообщение ("Спасибо за ответы, идет расчет..."), скрыть кнопки управления и показать красивый круговой лоадер (минимум 2 секунды, чтобы пользователь успел прочитать сообщение, или до завершения асинхронной задачи).

## 3. Обработка данных

- Структура вопроса (интерфейс `QuizQuestion`):
  ```ts
  interface QuizQuestion {
    id: string; // Уникальный идентификатор (часто код метрики, например RENT_EXPENSE)
    title: string;
    type: 'number' | 'single-choice' | 'multiple-choice';
    options?: { label: string; value: string | number }[]; // Для radio/checkbox
    placeholder?: string;
  }
  ```
- Ответы сохраняются в локальном стейте модалки (`Record<string, any>`), где ключ — это `question.id`, а значение — ответ пользователя.
- При завершении квиза вызывается callback `onComplete(answers)`, который передает объект с собранными данными родительскому компоненту.

## 4. Размещение

- Универсальный компонент `QuizModal.tsx` размещается в `components/ui/`.
- Вызов компонента осуществляется непосредственно на странице, которая его использует (например, `ForecastCurrentPage.tsx`), передавая нужный массив `questions`.
