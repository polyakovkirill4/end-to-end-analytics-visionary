# Инструкция: Управление правилами и навыками (Agent Config Manager)

Этот воркфлоу используется для проверки корректности настроек AI-агента, быстрого обновления правил и добавления новых навыков (Skills) по мере развития проекта.

## 1. Пошаговый процесс проверки (Чек-лист)

Перед тем как дорабатывать правила или навыки, проведи экспресс-аудит проекта:

### Шаг 1. Валидация файловой структуры
*   Проверь, соответствуют ли пути в `rules.md` реальному расположению папок в репозитории (например, нет ли папки `src`, правильно ли указаны директории `/pages`, `/components`, `/features`).
*   Если пути изменились, немедленно обнови файл `rules.md` (раздел *Архитектура и Структура файлов*).

### Шаг 2. Валидация зависимостей (`package.json`)
*   Открой `package.json` и проверь основные пакеты.
*   Убедись, что правила по React, PWA, Tailwind и State Management соответствуют версиям в зависимостях. 
*   *Например, если в проекте появился React 19, это должно быть отражено в правилах React Best Practices.*

## 3. Как правильно добавлять/изменять правила (Rules)

Правила в папке `.agent/rules/` срабатывают автоматически при работе агента.
При редактировании правил соблюдай следующие стандарты:

1.  **YAML Заголовок (Frontmatter)**:
    Каждое правило должно начинаться с заголовка:
    ```markdown
    ---
    trigger: model_decision
    description: Краткое описание на русском языке, когда применяется это правило
    ---
    ```
    Используй `trigger: always_on` для общих глобальных правил (таких как `rules.md` или `about-project.md`) и `trigger: model_decision` для контекстно-зависимых правил.
2.  **Сжатый и императивный тон**: Пиши правила четко, без лишней воды. Используй списки и выделение жирным шрифтом для критически важных требований (например, **MANDATORY**, **ЗАПРЕЩЕНО**).
3.  **Форматирование**: Ссылайся на файлы форматирования (например, `formatting-data.md`) вместо дублирования правил вывода чисел/дат.

## 4. Как правильно создавать/обновлять навыки (Skills)

Навыки находятся в папке `.agent/skills/[skill-name]/` и содержат файл `SKILL.md`.

### Структура папки навыка:
*   `.agent/skills/[skill-name]/SKILL.md` (Обязательно) — файл с описанием стандартов и примерами кода.
*   *Опционально*: папки `scripts/` (для вспомогательных скриптов валидации), `examples/` (для эталонных файлов).

### Шаблон файла `SKILL.md`:
```markdown
---
name: уникальное-имя-навыка
description: Описание на английском языке для системного распознавания.
---

# Название навыка на русском языке

Описание предназначения навыка и в каких случаях агент обязан его использовать.

## 1. Основные стандарты и правила
...
## 2. Примеры реализации (Code Snippets)
...
## 3. Чек-лист проверки
- [ ] Пункт 1
- [ ] Пункт 2
```
