Выполни роль Code Reviewer.

Проверь его на соответствие `rules.md` и стандартам качества:
1.  **Mobile First:** Корректно ли сделана адаптивность? Нет ли фиксированных ширин?
2.  **Performance:** Нет ли лишних ре-рендеров? Используются ли `useMemo`/`useCallback` там, где это нужно?
3.  **Logic Separation:** Отделена ли бизнес-логика (хуки) от UI? Если нет — предложи рефакторинг с выносом логики в `use[Name].ts`.
4.  **Error Handling:** Есть ли обработка ошибок (try/catch, toast notifications)?
5.  **Styling:** Используются ли утилиты Tailwind или `clsx` для условий?

Перепиши проблемные участки кода, сделав их чище и профессиональнее.
