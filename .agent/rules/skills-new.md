# Правило создания новых навыков (Agent Skills Proposal Rule)

Это правило регламентирует процесс расширения базы знаний ИИ-агентов через создание специализированных навыков (`SKILL.md`).

---

## 🧭 Когда предлагать создание нового навыка:
ИИ-агент должен проактивно предложить пользователю создать новый навык в папке `.agent/skills/[name]/`, если текущая задача:
1.  **Длинная и сложная**: Требует выполнения более 5-7 последовательных шагов или сложного рефакторинга.
2.  **Специфичная для домена**: Касается новых доменных областей (например, интеграция конкретного API, новые виды аналитики, специфичные математические расчеты).
3.  **Многоразовая**: Описывает паттерны разработки, которые пригодятся в будущем (настройки форм, новые чарт-компоненты, регламент работы со стейтом).

---

## 🚫 Запрет на автоматическое создание:
*   **ИИ-агенту СТРОГО ЗАПРЕЩЕНО создавать новые навыки самостоятельно** без явного согласия пользователя.
*   При обнаружении сложной задачи агент обязан:
    1.  Предложить пользователю создать навык.
    2.  Описать ценность этого навыка (как он поможет улучшить текущую и будущую работу).
    3.  Показать проект структуры файла `SKILL.md` (включая формулы, чек-листы и т.д.).
    4.  Запросить одобрение на создание.

---

## ⚙️ Требования к качеству файлов навыков (SKILL.md):
Каждый файл навыка должен создаваться профессионально для других ИИ-агентов и содержать:
1.  **YAML frontmatter** в начале файла с полями `name` и `description` (для корректной индексации).
2.  **Формулы и алгоритмы**: Четкие математические и логические выкладки с использованием разметки LaTeX ($$).
3.  **Примеры и кейсы**: Примеры кода, структур данных или интеграции.
4.  **Чек-лист проверки ИИ-агента**: Обязательный список шагов самопроверки перед написанием кода (например, проверка деления на ноль, типизация, адаптивность).
