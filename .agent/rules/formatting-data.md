Формат даты ДД.ММ.ГГГГ.
В заголовках — «ДД месяц ГГГГ», в таблицах — «ДД.ММ.ГГГГ».
Формат времени 24-часовой формат, через двоеточие.
Неделя начинается с ПН.
Названия месяцев и дней недели — со строчной буквы (если не начало предложения).
Валюта рубль. Сокращение "руб.".
Знак рубля «₽» ставить после суммы через пробел.
Для чисел по финансам, использовать неразрывный пробел ( &nbsp;) как разделитель тысяч, миллионов и другиз разрядов.
Если не целые число, по умолчанию цифры округлять до десятых, Целые числа не писать 0 десятых.
В финансах (рубли) для чисел использовать — 2 знака после запятой (копейки).
Округлять до сотых, если значение меньше 1%, в остальных случаях до десятых. Знак % пишется без пробела.
При расчете разницы количество дней учитывать основной день (плюс 1 день сделать).
При добавление количество дней для получения новой даты, нужно учитывать оснвоной день (отнять 1 день).
При отсутствии данных выводить прочерк «—», а не null или undefined.
Использовать длинное тире «—» вместо дефиса «-» при отсутсвии данных.
Использовать сокращения через пробел. Не ставить точку после «кг», «м».
Формат телефонного номера (маска): +7 (XXX) XXX-XX-XX.
Размеры файлов конвертировать в подходящую единицу измерения (1048576 -> 1.0 МБ).
Формат адреса: Порядок: Индекс, Город, Улица, Дом, Кв.
HTTP Статусы Код + Краткое описание (200 -> 200 OK, 404 -> 404 Not Found).
Время отклика В миллисекундах (ms), если > 1с — в секундах 1200ms -> 1.2 s.
Время «назад» Относительный формат для чатов/логов (5 min ago -> 5 мин. назад).
Ед. измерения Неразрывный пробел между числом и единицей (50 шт.).
Температура Знак + или —, округление до целого (+3°C).
Коэффициенты Всегда с «x» в конце (1.5 -> 1.5x).
Прогресс Целые числа без десятичных.
URL ссылок всегда низкий регистр.

### Готовые утилиты для форматирования в проекте
Все функции-хелперы и стандартные дефолтные значения описаны в файле: `@/utils/formatters.ts`. 

**Используй их напрямую в коде:**
1. `DEFAULT_VALUES` — объект с безопасными дефолтными пустыми значениями:
   - `DEFAULT_VALUES.NUMBER` (`0`)
   - `DEFAULT_VALUES.PERCENT` (`'0%'`)
   - `DEFAULT_VALUES.DATE` (`'01.01.2026'`)
   - `DEFAULT_VALUES.TIME` (`'00:00'`)
   - `DEFAULT_VALUES.STRING` (`''`)
   - `DEFAULT_VALUES.CURRENCY` (`'0 ₽'`)

2. `formatDate(date: Date | string | null | undefined): string` — форматирует дату в строгий строковый формат `ДД.ММ.ГГГГ`. При отсутствии даты возвращает `01.01.2026`.
3. `formatTime24(date: Date | string | null | undefined): string` — форматирует время в 24-часовой формат `ЧЧ:ММ`.
4. `formatCurrencyRUB(value: number | null | undefined, showPositiveSign?: boolean): string` — форматирует число как рубли с красивыми разделителями тысяч (неразрывные пробелы) и знаком `₽` в конце. Пример: `1320000` -> `"1 320 000 ₽"`. При `showPositiveSign: true` возвращает знак `+` перед положительным значением (удобно для дельты прибыли).
5. `formatPercentage(value: number | null | undefined): string` — форматирует число как проценты (например, `94` -> `"94%"`).
6. `generateUUID(): string` — генерирует уникальный UUID v4 на клиенте.

*Дополняй файл `@/utils/formatters.ts` новыми методами форматирования по мере необходимости.*
