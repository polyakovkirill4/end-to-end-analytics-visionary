Типы данных и сущностей, которые можно использовать в полях (инпут) при создании форм, модальных окон, фильтрации и связки элементов внутри аналитической платформы:

### 1. Системные и Временные поля
- Дата создания (created_at)
- Дата обновления (updated_at)
- Дата начала периода (фильтрация)
- Дата конца периода (фильтрация)
- Временной диапазон (день, неделя, месяц, квартал, год, кастомный)
- Расчет разницы между датами (сравнение с прошлым периодом)
- Статус элемента (активен, архивирован, в обработке)
- ID элемента (uuid)
- Название сущности
- Описание / Комментарий
- Теги / Категории (для группировки метрик)

### 2. Бизнес-Метрики и Аналитика
- Тип метрики (Финансовая, Маркетинговая, Продуктовая, Когортная)
- Формат метрики (Деньги, Проценты, Абсолютное число, Длительность)
- Формула расчета метрики (для кастомных показателей)
- Плановое значение (KPI / Target)
- Фактическое значение
- Отклонение от плана (в % или абсолютных значениях)
- Уровень критичности отклонения (норма, предупреждение, критично)
- Источник данных для метрики (ручной ввод, интеграция)

### 3. Маркетинг и Воронки
- Источник трафика / Рекламный канал
- UTM-метки (source, medium, campaign, content, term)
- Стоимость привлечения (CAC)
- Конверсия (CR на каждом этапе воронки)
- Количество лидов / сделок
- Стадия сделки в воронке конверсии
- Средний чек (AOV)
- Оценка лояльности (NPS)

### 4. Финансы и Биллинг
- Выручка (Revenue)
- Постоянный доход (MRR / ARR)
- Расходы (OpEx / CapEx)
- Статья расходов (категория финансов)
- Чистая прибыль (Net Profit)
- EBITDA / Маржинальность
- Расчетный счет / Валюта
- Финансовая транзакция (расход, приход, перевод)
- Тарифный план клиента (подписка на SaaS)
- Баланс аккаунта / Дата следующего списания по тарифу

### 5. Сегментация и Пользователи
- Когорта пользователей (по дате регистрации / первой покупки)
- Сегмент клиентов (по объему выручки, LTV, частоте покупок)
- Пользователь платформы (Администратор, Аналитик, Просмотрщик)
- Активность пользователя (Session duration, DAU/MAU)
- Churn Rate (показатель оттока клиентов)

### 6. Интеграции и Системные Настройки
- Сервис интеграции (Supabase, Google Analytics, Yandex Metrica, Stripe, Billing, Банки)
- API Ключ / Токен доступа
- Статус подключения интеграции (активно, ошибка авторизации, синхронизация)
- Дата последней успешной синхронизации данных
- Лог синхронизации (журнал событий)
